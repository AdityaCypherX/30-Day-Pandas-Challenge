✅ Problem Solved
📘 176. Second Highest Salary
Difficulty: Medium
Concepts Used:
Removing duplicates (drop_duplicates())
Sorting (sort_values())
Index-based selection (iloc)
Edge case handling
📝 Problem Summary
Find the second highest distinct salary from the Employee table.
If there is no second highest salary, return null (None in Pandas).
🧠 Core Logic
Extract distinct salaries
Sort them in descending order
Return the second value if it exists
Otherwise return None

Writing clean and readable Pandas solutions
